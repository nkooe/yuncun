# 宝塔面板部署教程

> 本教程基于 **宝塔 8.0.5 + Nginx 1.30.6 + PHP 8.2** 实测完成，
> 每一步都验证过结果，坑点均来自真实踩坑记录。

---

## 一、环境准备

### 宝塔安装必要软件

```
软件商店 → 运行环境
  ├─ Nginx        1.22+（推荐 1.24 或更高）
  └─ PHP          8.1 或 8.2

软件商店 → PHP 8.2 → 设置 → 安装扩展
  必需：pdo_mysql、mbstring、json（宝塔默认已装）
  推荐：fileinfo、gd、zip、openssl
```

### 检查 PHP 扩展

在 `网站 → 设置 → 配置文件` 上方有「PHP版本」，确认至少 8.1。

**fileinfo 缺失不影响使用**，只是上传时无法精确判断 MIME 类型分片校验会宽松一点。

### 调整 PHP 上传限制

```
软件商店 → PHP 8.2 → 设置 → 配置修改
```

改成：

```ini
upload_max_filesize = 50M
post_max_size       = 50M
memory_limit        = 128M
max_execution_time  = 300
```

保存后**重启 PHP**。

> 分片大小会自动取 `min(32MB, upload_max_filesize × 0.8)`。
> 给 50M → 分片 32MB → 1GB 文件只需 32 片。

## 二、创建站点

```
网站 → 添加站点

  域名：      你的域名（如 pan.example.com）
  根目录：    /www/wwwroot/pan.example.com
  FTP：       不创建
  数据库：    MySQL，字符集 utf8mb4
  PHP版本：   8.2
```

创建后宝塔会自动生成：

```
站点目录        /www/wwwroot/pan.example.com
Nginx 配置      /www/server/panel/vhost/nginx/pan.example.com.conf
伪静态文件      /www/server/panel/vhost/rewrite/pan.example.com.conf
```

记下数据库名和密码，安装向导要用。

---

## 三、上传代码

把项目文件传到站点根目录，**保留空目录结构**：

```
storage/files/
runtime/chunks/
runtime/cache/
runtime/logs/
```

用宝塔「文件」管理器上传 zip 解压即可。

### 目录权限

```
文件 → 选中站点目录 → 权限

  所有者：www
  权限：  755
  应用到子目录：勾选
```

然后单独给这三个目录 775：

```bash
chown -R www:www /www/wwwroot/pan.example.com
chmod -R 775 /www/wwwroot/pan.example.com/storage \
             /www/wwwroot/pan.example.com/runtime \
             /www/wwwroot/pan.example.com/data
```

> **坑**：`chmod -R 775 data` 会把 `data/config.php` 一起放宽到 775。
> 安装完成后必须单独收紧，见第九节。

---

## 四、配置伪静态（必须，否则全站 404）

```
网站 → 设置 → 伪静态
```

粘贴：

```nginx
location / {
    try_files $uri $uri/ /index.php$is_args$args;
}
```

保存。

### 这一步做什么

系统是单入口路由，所有 URL（`/login`、`/admin`、`/categories`）在磁盘上都不存在，
靠 `index.php` 按路径分发。

**不配伪静态的实测结果**：

```
/              → 302    （index 生效）
/login         → 404    ✗
/admin         → 404    ✗
/categories    → 404    ✗
/install.php   → 200    （真实文件）
```

**配了之后**：

```
/              → 302
/login         → 302    ✓
/admin         → 302    ✓
/categories    → 302    ✓
```

（302 是因为还没安装，自动跳安装页，属正常）

## 五、配置站点配置文件（必须，安全防线）

```
网站 → 设置 → 配置文件
```

在 `server { }` 内、`include enable-php-82.conf;` 之前，插入：

```nginx
# ---------- 上传与超时 ----------
client_max_body_size 512m;
client_body_timeout  300s;
fastcgi_read_timeout 900s;
fastcgi_send_timeout 900s;
send_timeout         900s;

# ---------- 敏感目录：唯一防线 ----------
location ^~ /storage/ { deny all; return 403; }
location ^~ /data/    { deny all; return 403; }
location ^~ /runtime/ { deny all; return 403; }

# 隐藏文件（.git / .env / .htaccess）
location ~ /\.(?!well-known) { deny all; return 403; }

# ---------- 大文件下载不压缩 ----------
gzip off;
```

保存，宝塔会自动 reload。

### 为什么必须加这三段

项目自带 `.htaccess` 和 `web.config`，但：

- `.htaccess` → Apache 用
- `web.config` → IIS 用
- **Nginx 完全不理它们**

**不加的实测结果**：

```
/data/config.php                → 200   ← 数据库密码文件被 PHP 执行
/storage/files/ab/cd/test.bin   → 200   ← 用户上传的文件被直接下载
/.htaccess                      → 200   ← 配置文件被下载
```

**加了之后**：

```
/data/config.php                → 403 ✓
/data/install.lock              → 403 ✓
/storage/files/                  → 403 ✓
/runtime/logs/                   → 403 ✓
/.htaccess                       → 403 ✓
```

`storage/files/` 里是**所有人上传的全部文件**，没有这三段等于把网盘内容公开成静态资源。

### 为什么 fastcgi_read_timeout 要 900s

Nginx 默认 60 秒。下载大文件时 PHP 要持续输出，超过就被切断。

实测：60KB/s 的线路下，100MB 文件要传 28 分钟，默认配置第 60 秒就断。

## 六、关闭防跨站（视情况）

```
网站 → 设置 → 网站目录
  防跨站攻击(open_basedir)：关闭
```

**默认可以不管**（项目所有读写都在站点目录内）。

**必须关闭的情况**：你把 `storage` 软链到别的磁盘（数据盘），
open_basedir 会拦住 PHP 访问站点目录之外的路径，上传会报「无法创建文件」。

## 七、访问安装向导

浏览器打开你的域名，会自动跳到 `install.php`。

### 第 1 步：环境检测

13 项检查，全部打勾。

`fileinfo` 显示「未加载」不影响，那是推荐项。

### 第 2 步：数据库配置

| 字段 | 填什么 |
|---|---|
| 数据库地址 | `127.0.0.1` |
| 端口 | `3306` |
| 数据库名 | 第二节创建的那个 |
| 用户名 | 同上 |
| 密码 | 同上 |
| 表前缀 | `wx_`（默认） |

点击「测试连接并继续」。

### 第 3 步：站点与管理员

- 站点名称：随便填
- 站点 URL：留空自动识别
- 管理员账号：`admin`
- 管理员密码：**至少 6 位**
- 邮箱：可选

### 第 4 步：确认

核对信息，点「开始安装」。

### 第 5 步：完成

显示「安装完成」，并写入：

```
data/config.php      数据库连接
data/install.lock    安装锁
```

**此后 `install.php` 会显示「系统已安装」并拒绝访问。**

## 八、安装后必须做的三件事

### ① 删除或封禁 install.php

```bash
mv /www/wwwroot/pan.example.com/install.php \
   /www/wwwroot/pan.example.com/install.php.disabled
```

或者用宝塔的「网站目录 → 防篡改」保护起来。

### ② 收紧配置文件权限

安装向导生成 `config.php` 时用的是默认权限，需要收紧：

```bash
chmod 640 /www/wwwroot/pan.example.com/data/config.php
chmod 750 /www/wwwroot/pan.example.com/data
```

**为什么**：如果之前执行过 `chmod -R 775 data`，`config.php` 会是 775，
同服务器其他站点的用户可能读到数据库密码。

### ③ 开启 HTTPS

```
网站 → 设置 → SSL → Let's Encrypt → 申请
```

申请成功后开启「强制HTTPS」。

## 九、验证清单

依次访问，对照结果：

| 路径 | 期望 | 说明 |
|---|---|---|
| `/` | 200 | 前台首页 |
| `/login` | 200 | 登录页 |
| `/admin` | 302 | 跳转登录（不是 404） |
| `/categories` | 200 | 分类页 |
| `/install.php` | 403 或 404 | 已锁定 |
| `/data/config.php` | **403** | 绝对不能是 200 |
| `/storage/files/` | **403** | 绝对不能是 200 |
| `/runtime/logs/` | **403** | 绝对不能是 200 |
| `/.htaccess` | **403** | 绝对不能是 200 |

**最后四行是重点**，返回 200 说明敏感目录裸奔。

### 命令行一次性检查

```bash
for p in / /login /admin /categories /install.php \
         /data/config.php /storage/files/ /runtime/logs/ /.htaccess; do
  printf "%-22s %s\n" "$p" "$(curl -s -o /dev/null -w '%{http_code}' -k https://你的域名$p)"
done
```

## 十、常见问题

### 全站 404

伪静态没配，或配错位置。检查 `网站 → 设置 → 伪静态` 内容是否为：

```nginx
location / {
    try_files $uri $uri/ /index.php$is_args$args;
}
```

### 安装页显示「系统已安装」但要重装

删除两个文件：

```bash
rm /www/wwwroot/pan.example.com/data/config.php
rm /www/wwwroot/pan.example.com/data/install.lock
```

### 上传失败，提示「无法创建分片目录」

1. `storage`、`runtime` 目录权限不是 775
2. 所有者不是 www
3. open_basedir 拦住了（如果你挂了软链）

```bash
chown -R www:www /www/wwwroot/pan.example.com
chmod -R 775 /www/wwwroot/pan.example.com/storage /www/wwwroot/pan.example.com/runtime
```

### 上传大文件失败

三层限制都要放开：

```
① PHP：upload_max_filesize / post_max_size
② Nginx：client_max_body_size
③ 后台：系统设置 → 单文件上限
```

### 下载大文件中途断开

`fastcgi_read_timeout` 太小。改成 900s。

### 页面样式错乱

浏览器缓存了旧 CSS。项目静态资源带 `?v=文件修改时间` 会自动刷新，
强制刷新一次（Ctrl+F5）即可。

### 忘记管理员密码

```bash
php -r 'echo password_hash("新密码", PASSWORD_DEFAULT), PHP_EOL;'
```

把输出写进数据库：

```sql
UPDATE wx_users SET password_hash = '上面输出的哈希' WHERE username = 'admin';
```

### 登录提示「失败次数过多」

默认：同一账号错 5 次锁 60 分钟，同一 IP 错 20 次锁 60 分钟。

解锁：

```sql
DELETE FROM wx_login_logs WHERE status IN ('fail','locked');
```

或者在 `系统设置 → 登录锁定时长` 调整。

## 十一、可选：配置自动备份

在站点目录之外建脚本（`/www/wwwroot/.backup/backup-db.sh`）：

```bash
#!/bin/bash
set -e
BAK=/www/wwwroot/.backup/db
mkdir -p "$BAK"
chmod 700 /www/wwwroot/.backup "$BAK"

PW='你的数据库密码'
OUT="$BAK/pan-$(date +%Y%m%d-%H%M%S).sql.gz"

mysqldump -u root -p"$PW" \
  --single-transaction --quick --skip-lock-tables \
  --default-character-set=utf8mb4 \
  你的数据库名 2>/dev/null | gzip -6 > "$OUT"

gzip -t "$OUT" || { echo "备份校验失败" >> "$BAK/backup.log"; exit 1; }
find "$BAK" -name 'pan-*.sql.gz' -mtime +14 -delete
echo "[$(date)] OK $(basename $OUT)" >> "$BAK/backup.log"
```

```bash
chmod 700 /www/wwwroot/.backup/backup-db.sh
```

宝塔「计划任务」新建：

```
任务类型：Shell脚本
执行周期：每天 3:15
脚本内容：/www/wwwroot/.backup/backup-db.sh
```

## 十二、坑点汇总

| # | 坑 | 后果 | 解决 |
|---|---|---|---|
| 1 | 不配伪静态 | 除首页外全 404 | `try_files $uri $uri/ /index.php$is_args$args` |
| 2 | 不加 `/storage/` `/data/` `/runtime/` deny | **用户文件、数据库密码可被直接下载** | 三段 `location ^~ ... deny all` |
| 3 | 依赖 `.htaccess` | Nginx 完全无视 | 必须手写 Nginx 规则 |
| 4 | `fastcgi_read_timeout` 默认 60s | 大文件下载被切断 | 改 900s |
| 5 | `chmod -R 775 data` | config.php 权限过宽 | 安装后单独 `chmod 640` |
| 6 | install.php 不删 | 重装风险 | 移到站点外或封禁 |
| 7 | open_basedir + storage 软链 | 上传失败 | 关闭防跨站 |
| 8 | PHP 上传限制没改 | 大文件上传失败 | 三层都要放开 |
| 9 | 磁盘满 | MySQL 崩，不只是上传失败 | 后台开「磁盘水位保护」 |
